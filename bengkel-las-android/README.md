# Bengkel Las Karya Tunas Muda

Aplikasi Android sederhana untuk membantu operasional bengkel las.

## Fitur MVP
- Dashboard omzet dan jumlah pesanan
- Pencatatan pesanan pelanggan
- Kalkulator luas dan estimasi harga per m²

## Pengembangan berikutnya
- RAB otomatis besi hollow, plat, galvanis, cat dan aksesoris
- Database pelanggan dan proyek
- Status pekerjaan: survey, produksi, finishing, selesai, lunas
- Cetak/share invoice dan penawaran
- Backup data
- Kalkulator berat besi dan kebutuhan material
